# Maquettes Site Express — Mokom Studio

Catalogue de 11 thèmes de sites personnalisables (exemples A et B), affiché sur https://maquettes.mokomstudio.fr

- `index.html` : vitrine (cadres ordinateur / téléphone, exemple A / B, fonctionnalités)
- un fichier `.html` par page de maquette
- `img/` : photos (Pexels, libres de droits)

Toutes les pages sont en `noindex` : ce sont des entreprises fictives de démonstration.
